# INVIMA CONSCIENTE · Cartilla interactiva NO ES NORMAL

Cartilla digital horizontal e interactiva para socializar el Protocolo INVIMA CONSCIENTE (Res. 2026041802 de 2026) y la campaña «NO ES NORMAL. Lo que se nombra, se detiene.»

Versión de prueba. Contenidos sujetos a validación institucional.

## Estructura
- `index.html` · página principal
- `css/app.css` · estilos
- `js/data.js` · todos los textos, casos, tarjetas y actividades (editar aquí)
- `js/app.js` · funcionamiento
- `img/` · logos y personajes
- `video/` · (pendiente) archivos MP4 de los videos; se enlazan en `js/data.js` → `VIDEOS`
